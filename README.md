# Smart Pipette

The pipette (middle mouse) on empty ground picks the block that works there: a plasma bore for ore in a wall, a cliff crusher for a wall, a condenser for a steam vent, a drill for ore, a pump for liquid, a core for a core zone. Click again for the next one; after the last one the hand is empty.

![Smart Pipette](https://raw.githubusercontent.com/m3rcur1e/smart-pipette/media/smart-pipette.webp)

Uses the vanilla **Pick** key (Settings › Controls).
